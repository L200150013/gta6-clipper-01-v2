## The entry

`VIDEO.json` names the Short. `main.ts` (Node 22, standard library only)
validates the link and copies `VIDEO.json` to the output directory — that is
all the program does; the house reads the video's views itself through the
YouTube Data API, and places go by views at the deadline.
